死妈中介和营销号害人不浅，我不想每次有人问我各种事情我都得长篇大论解释一遍了，所以直接写一个全指南以后一律甩链接完事  

### 开始阅读

在开始阅读本指南之前，琴梨梨假设你已经达到了下列条件：   

- [X] 已经获得了一所澳洲学校的[CoE](https://immi.homeaffairs.gov.au/help-text/eplus/Pages/elp-h1621.aspx)
- [X] 已经获批了可以合法受教育的签证（通常为[500](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/student-500)）
- [X] 已经除了学费外准备了至少等值 A$ 20,000 的可在澳洲消费货币额度 （少于这个额度会使你开荒困难，注意银联卡里的人民币这类不可在澳洲消费额度不可计入）
- [X] 直到落地前，一个稳定的能访问Google的网络条件
- [X] 至少等效于雅思学术阅读7.5分的英语阅读能力 （本仓库不对任何英文引用链接做翻译，你阅读拿不到7.5你来了和唐氏儿也没两样）

本指南不会提供如何达成上述条件的任何帮助
